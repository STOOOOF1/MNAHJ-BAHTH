# مناهج البحث الاقتصادي — حزمة مذاكرة

مقرر «مناهج البحث الاقتصادي» — برنامج ماجستير الاقتصاد الإسلامي، كلية الأنظمة والاقتصاد، الجامعة الإسلامية بالمدينة المنورة.

| الملف | الوصف |
|---|---|
| `مذكرة-مناهج-البحث-الاقتصادي.pdf` | المذكرة الأساسية للمقرر (99 صفحة)، جمع وإعداد د. عبد السلام أحمد سومر |
| `ملخص-مناهج-البحث-الاقتصادي.pdf` | ملخص المذكرة في 10 صفحات: خرائط ذهنية وجداول مقارنة وأشجار تصنيف |
| `index.html` | موقع بطاقات المراجعة: 100 بطاقة على 4 مستويات (10 · 20 · 30 · 40)، بزر «تم» يحفظ التقدم في المتصفح. المستويات كلها مفتوحة، وزر «🔗 انسخ رابط تقدّمك» يحفظ ما أنجزته وموضعك في الرابط نفسه فيعيدك إليه ولو مُسح حفظ المتصفح. |
| `level3/index.html` | صفحة هبوط مقررات المستوى الثالث الستة: لكل مقرر المذكرة ثم الملخص ثم البطاقات — `https://stoooof1.github.io/MNAHJ-BAHTH/level3/` |
| `game/` | لعبة «مدينة الباحث» ثلاثية الأبعاد: ستة أحياء و58 درسًا ومحاكيات واختبارات وشهادة إتمام (انظر `game/README.md`) |

## موقع البطاقات

افتح `index.html` في المتصفح مباشرة، أو فعّل GitHub Pages للمستودع (Settings ← Pages ← Branch: `main` / root) ليصبح الموقع على:
`https://stoooof1.github.io/MNAHJ-BAHTH/`

واللعبة على: `https://stoooof1.github.io/MNAHJ-BAHTH/game/`

> عبارات «حفظ» و«لا تخلط» في الملخص والبطاقات إضافات للمراجعة من خارج نص المذكرة.
