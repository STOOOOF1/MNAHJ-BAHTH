# مناهج البحث الاقتصادي — حزمة مذاكرة

مقرر «مناهج البحث الاقتصادي» — برنامج ماجستير الاقتصاد الإسلامي، كلية الأنظمة والاقتصاد، الجامعة الإسلامية بالمدينة المنورة.

## هيكل المستودع

| المجلد | ما فيه |
|---|---|
| `files/` | الملفات المرفقة: المذكرة والملخص |
| `sites/` | المواقع والصفحات: `sites/cards/` موقع البطاقات، و`sites/level3/` صفحة هبوط مقررات المستوى الثالث الستة |
| `games/` | الألعاب التعليمية: `madinat-albahith/` (مدينة الباحث) |
| `index.html` | بوابة المقرر: روابط المذكرة والملخص والبطاقات والألعاب |

> ⚠️ الملخصات والبطاقات والألعاب أُعدّت عبر نماذج الذكاء الاصطناعي ولم تتقدّم مراجعتها ولا تدقيقها؛ والتحقق منها مطلوب من الطالب مع مطابقتها بالمذكرة المعتمدة.

| الملف | الوصف |
|---|---|
| `files/مذكرة-مناهج-البحث-الاقتصادي.pdf` | المذكرة الأساسية للمقرر (99 صفحة)، جمع وإعداد د. عبد السلام أحمد سومر |
| `files/ملخص-مناهج-البحث-الاقتصادي.pdf` | ملخص المذكرة في 10 صفحات: خرائط ذهنية وجداول مقارنة وأشجار تصنيف |
| `sites/cards/` | موقع بطاقات المراجعة: 100 بطاقة على 4 مستويات (10 · 20 · 30 · 40)، بزر «تم» يحفظ التقدم في المتصفح. المستويات كلها مفتوحة، وزر «🔗 انسخ رابط تقدّمك» يحفظ ما أنجزته وموضعك في الرابط نفسه فيعيدك إليه ولو مُسح حفظ المتصفح. |
| `sites/level3/` | صفحة هبوط مقررات المستوى الثالث الستة: لكل مقرر المذكرة ثم الملخص ثم البطاقات — `https://stoooof1.github.io/MNAHJ-BAHTH/sites/level3/` |
| `games/madinat-albahith/` | لعبة «مدينة الباحث» ثلاثية الأبعاد: ستة أحياء و58 درسًا ومحاكيات واختبارات وشهادة إتمام (انظر `games/madinat-albahith/README.md`) |

## موقع البطاقات

افتح `sites/cards/index.html` في المتصفح مباشرة، أو فعّل GitHub Pages للمستودع (Settings ← Pages ← Branch: `main` / root) فتكون بوابة المقرر على:
`https://stoooof1.github.io/MNAHJ-BAHTH/`
والبطاقات على: `https://stoooof1.github.io/MNAHJ-BAHTH/sites/cards/`

واللعبة على: `https://stoooof1.github.io/MNAHJ-BAHTH/games/madinat-albahith/`

> عبارات «حفظ» و«لا تخلط» في الملخص والبطاقات إضافات للمراجعة من خارج نص المذكرة.
